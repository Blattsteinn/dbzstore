# accountrift

Live view - [accountrift.com](https://accountrift.com)

Simple e-commerce web application built with **Ruby on Rails 8** for personal usage. Featuring  product listings, Stripe checkout and an admin dashboard.

## Features
- **Product catalogue** — Browse products with multiple images, variants (title, price, stock), and visibility controls (live/hidden), can checkout instantly or via cart
- **Stripe integration**
- **Admin dashboard** — Manage products, orders, feedbacks, and FAQs from a central interface

## Stack

- **Ruby on Rails 8.1**
- **PostgreSQL**
- **Hotwire** (Turbo + Stimulus)
